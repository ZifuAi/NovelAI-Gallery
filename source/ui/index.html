Tags or prose
At 0 every bucket is comma-separated Danbooru tags. Turning it up rewrites the descriptive buckets as a sentence and leaves artists, character count and composition as tags, which is what V4.5 responds to best.
Character from a series
A character tag carries its own hair, eyes and outfit, so turning this on also switches off the buckets that would argue with it.

### Folders

- Nested subfolders — drag a folder into another, out to the top level, or between rows to reorder
- Rename folders, and give them tags that are searchable like everything else
- Counts roll up: a parent shows everything underneath it
- A folder can't be dropped inside itself
- The sidebar is resizable, and the layouts re-flow to fit it

### Undo and redo

- `Ctrl+Z` / `Ctrl+Shift+Z` for anything that changes your library — deletes, moves, renames, folder reshuffles, colour labels, bulk actions
- Deleted images go to a trash folder, so undoing a delete brings back the file, not just its entry

### Colour labels

- Per-image colour labels, from the right-click menu or the details panel
- The sort dropdown has been redesigned and now doubles as the colour filter
- Name your colours in **Settings ▸ Library**

### Automatic updates

- Checks this page's releases on the first open of the day, and offers the new build in the corner
- Downloads, installs, reopens, then shows you these notes
- **Settings ▸ About** has a manual check and a switch for doing it automatically
- No server involved — it reads this repository's releases directly

### Also

- The installer now upgrades an existing install in place, leaving your library alone
- New defaults: waterfall layout, details panel off, metadata sections collapsed
- Settings is split into four tabs: Appearance, Library, Capture, About
- `Esc` now closes the sort menu and the folder popover, not just modals
